# Text-to-3D Jewellery Generation

Exploring text-to-3D generation using Stable DreamFusion, NeRF, and diffusion-based pipelines.

---

## Overview

This project investigates how natural language prompts can be transformed into 3D jewellery-style objects using Neural Radiance Fields (NeRF) and diffusion-guided generation techniques.

The work is based on research and experimentation with Stable DreamFusion and related text-to-3D architectures.

---

## Objectives

- Explore text-to-3D generation workflows
- Understand NeRF-based scene representation
- Experiment with diffusion-guided 3D synthesis
- Generate exportable 3D mesh objects
- Document architecture limitations and outputs

---

## Tech Stack

- Python
- PyTorch
- Stable DreamFusion
- NeRF
- Diffusion Models
- GLTF / Mesh Processing
